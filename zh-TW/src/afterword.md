# 後記

就算閱讀完這份教材了，也不代表你已經精通電腦科學，而只是學習到了 Rust 這個程式語言大致上的設計與撰寫 Rust 程式的方法。事實上，這本書對許多概念都進行了簡化。如果讀者還想要更深入地學習程式設計，我會先建議學習**資料結構**，無論是參與大學課程，閱讀書籍，或者上網尋找其他教學。本教材最主要的目標客群是完全沒有程式設計經驗的人，因此大幅簡化了關於資料結構以及計算複雜度的說明。除此之外，本教學也僅用了非常少的篇幅解釋 `unsafe`，在這方面我推薦 [*The Rustonomicon*](https://doc.rust-lang.org/nomicon/) 這本書；儘管 The Rustonomicon 的內容還不完整，甚至可能永遠都不會完整，但它已經是對於 Rust 和硬體底層互動方式最好的教材了。

如果你想要接觸底層硬體的話，你或許還會需要學習例如 C 之類的另一個程式語言，因為絕大多數常用的程式語言都有對 C 的 FFI。但或許你和我一樣，對程式語言而非硬體比較感興趣，那樣的話，你可能會想接觸更偏向學界所使用的程式語言，例如純函數式的 Haskell，甚至是能拿來做數學證明的 Agda 或 Lean。儘管那些高階語言的設計理念與 Rust 大不相同，Rust 也從它們上頭借鑒了不少，因此你前面學習 Rust 所花的時間並沒有白費掉。誰知道未來流行的會不會是那些程式語言呢？

雖然有點晚了，但我想在最後的最後感謝我的家人，讓我得以學習我想學習的知識，並完成這份教學。
